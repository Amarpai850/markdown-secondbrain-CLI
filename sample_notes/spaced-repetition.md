# Spaced Repetition and Memory Retention

Spaced repetition is an evidence-based learning technique that incorporates increasing intervals of time between subsequent review of previously learned material.

## The Forgetting Curve

Hermann Ebbinghaus discovered that memory decay follows an exponential decay function. Active recall right before forgetting consolidates neural pathways into long-term memory.

## Algorithms and Systems

- **Leitner System**: Card boxes with graduated progression based on recall success.
- **SuperMemo (SM-2)**: Mathematical scheduling using difficulty factors and repetition counts.
