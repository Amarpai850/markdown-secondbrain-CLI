# Building a Second Brain Methodology

Developed by Tiago Forte, Building a Second Brain (BASB) is a systematic methodology for saving and organizing digital information to enhance creative output.

## The CODE Framework

- **Capture**: Save resonant insights, quotes, and artifacts.
- **Organize**: Categorize by actionability using the PARA method (Projects, Areas, Resources, Archives).
- **Distill**: Extract the essence via [[progressive-summarization]].
- **Express**: Transform curated knowledge into tangible work and creative output.

Complements personal knowledge systems like the [[zettelkasten-method]] and authoring [[evergreen-notes]].
