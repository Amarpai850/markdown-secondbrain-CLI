# The Zettelkasten Method

The Zettelkasten is a personal knowledge management system developed by sociologist Niklas Luhmann that emphasizes atomic notes and emergent connections.

## Core Rules

1. **Atomicity**: Each note contains exactly one single idea or concept.
2. **Autonomous Units**: Notes are self-contained and intelligible independently.
3. **Bidirectional Links**: Cross-referencing between notes creates organic clusters of thought rather than rigid hierarchies.

## Note Categories

- **Fleeting Notes**: Temporary thoughts captured spontaneously.
- **Literature Notes**: Summaries of external sources and readings.
- **Permanent Notes**: Finished thoughts integrated into the main slip-box.
