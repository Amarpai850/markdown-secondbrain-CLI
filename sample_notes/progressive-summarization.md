# Progressive Summarization Technique

Progressive Summarization is a method for distilling notes through multiple layers of compression while preserving the original context.

## The Five Layers

1. **Layer 1: Raw Capture**: Unfiltered excerpt or transcript.
2. **Layer 2: Bold Passages**: Bold the key phrases across the note.
3. **Layer 3: Highlights**: Highlight only the most insightful bold phrases.
4. **Layer 4: Mini-Summary**: Write a 2-3 bullet point synthesis at the top.
5. **Layer 5: Remix**: Repurpose the insight into an external project.

Forms the distill stage of the CODE framework in [[second-brain-methodology]] and facilitates creating [[evergreen-notes]].
